# Rapport — Test élève (persona 13 ans, seul, sans aide) — Unité 1
Date : 2026-11-09 · Méthode : parcours réel sur la plateforme (entrée → séance 1 complète jusqu'au quiz ; séances 2-3 échantillonnées + inventaire).

## Ce qui marche bien
- Entrée claire : pastilles de classe, cartes seul/binôme ; **un nom en arabe (« ياسين العمراني ») est accepté**.
- Reprise exacte à l'endroit arrêté (bannière « tu reprends ton parcours ici »).
- Exercices gestes 1-3 (cibles, double-clic, saisie + bouton Entrée) intuitifs et ludiques.
- Trace écrite séance 1 : 183 mots seulement.
- Quiz : bouton « Recommencer » clair ; révision des questions proposée.

## Difficultés trouvées (par gravité)
1. **Blocage total sur les questions de connaissance dans l'atelier** — S1 ex.4 « Construire le mot » et ex.5 « Choisir la bonne définition » : le bouton « Exercice suivant » reste désactivé tant que la réponse est fausse ; aucun indice, aucun renvoi vers la leçon, aucune possibilité de passer et revenir. Seule issue : le petit lien « Voir mon bilan ». Un élève seul se retrouve coincé dès la première lacune.
2. **Le français domine le contenu** — mission (188 mots, « Situation-problème » en français d'abord), consignes, définitions, trace : l'arabe est secondaire. La barrière réelle pour un élève de 13 ans arabophone est la compréhension du français, pas les gestes.
3. **Réponses devinables par la forme** — ex.5 : la bonne réponse est la plus longue/formelle (C). Quiz S1 : choisir toujours la 1re option donne 4/6 = réussite (seuil = la moitié). On peut « réussir » sans apprendre.
4. **Atelier long + note décourageante** — 14 exercices (~35-50 min pour un débutant seul). Le bilan intermédiaire affiche une note (5,7/20 à 29 %) : effet punition plutôt qu'encouragement.
5. **Aucune explication sur le bouton désactivé** — l'élève ne sait pas pourquoi il ne peut pas avancer.
6. **Mission très textuelle avant la première manipulation** — les premières minutes sont de la lecture, pas de l'action.

## Correctifs prioritaires proposés
1. Système anti-blocage dans le lecteur d'exercices : après 2 échecs → indice + bouton « revoir la leçon » ; option « passer et revenir » (l'exercice reste marqué à reprendre).
2. Consignes arabe d'abord dans les exercices (au minimum la consigne).
3. Mélanger les positions des réponses (atelier + quiz), équilibrer les longueurs ; masquer la note /20 en cours de route, messages d'encouragement aux étapes (5/10/14).
4. Message clair sous le bouton suivant désactivé : « أكمل هذا التمرين لتفتح التالي ».
5. Mission : raccourcir/illustrer l'entrée, premier geste dès la première minute.
